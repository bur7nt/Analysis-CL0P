### Анализ вымогателя CL0P (Linux)

Вымогатель становится демоном, переходит в корень и шифрует файлы в каталогах
/opt, /home, /root и /u01–/u04 (точки монтирования Oracle). В каждом каталоге
оставляет файл с контактами злоумышленников. Файлы шифруются алгоритмом RC4
(не более 100 МБ на файл), ключ из 117 символов генерируется отдельно для
каждого файла. Этот ключ шифруется тем же RC4 ключом, зашитым в бинарник,
и сохраняется рядом с файлом с маркером .C_I_0P. Поэтому файлы можно
расшифровать без злоумышленников.
